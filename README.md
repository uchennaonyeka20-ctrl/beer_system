# Beer System
A web-based beer shop management and ordering system built with PHP and MySQL. It allows an admin to manage the beer shop inventory, and allows customers to browse available beers and place orders.

# Features
- Form input
- Manage Stock
- Add Beer
- Delete Beer
- Select Items
- View Order
- Generate Receipt

# Technologies Used
- PHP
- MySQL
- HTML
- CSS
